# Сайт приложения «В расчёте»

Страница приложения, публичная оферта и политика конфиденциальности.
Публикуется через GitHub Pages (Jekyll собирается автоматически).

## Как заполнить свои данные

1. Откройте файл `_config.yml` → значок карандаша (Edit).
2. Замените текст в квадратных скобках: ФИО, ИНН, город, email, телефон.
3. Commit changes. Через 1–2 минуты сайт обновится.

Больше ничего править не нужно — данные подставятся на все страницы.

## Страницы

- `/` — описание приложения, цена Pro, порядок оплаты и возврата, контакты
- `/offer/` — публичная оферта
- `/privacy/` — политика конфиденциальности
